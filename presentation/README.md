# Superstore Sales & Profit Dashboard Presentation

This presentation provides a summary of the Superstore Sales & Profit Dashboard project.

## Contents

- Project objective
- Dataset overview
- Sales and profit performance
- Regional performance
- Category and sub-category profitability
- Monthly sales and profit trends
- Discount versus profit analysis
- Key business insights
- Recommendations

## Purpose

The presentation communicates the major findings from the Tableau dashboard in a concise and business-friendly format.

## Tools Used

- Tableau Public
- Microsoft Excel
- GitHub
- Python

## Dashboard

The accompanying Tableau dashboard provides interactive analysis of sales, profitability, customers, orders, regions, categories, discounts, and monthly trends.
